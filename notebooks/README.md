# Notebook

`tp2_detector_spam.ipynb` es el notebook principal: importa `punto1.py`,
`punto2.py`, `punto3.py` y `utils.py` de `src/tp2/`, los combina en los
experimentos y presenta resultados, figuras y pruebas. Debe contener, en
orden, configuración reproducible, carga del dataset, una sección por punto
del enunciado, comparación de resultados, pruebas unitarias y conclusiones.

Las implementaciones no se escriben aquí: van en el archivo del punto
correspondiente. No crear copias personales dentro de esta carpeta. Las
pruebas temporales deben realizarse fuera del repositorio o en ramas de
trabajo y descartarse antes de integrar cambios.
